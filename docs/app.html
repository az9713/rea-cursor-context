Context Evidence Ledger

When an AI coding edit surprises you, it helps to inspect the activity around it. This tool records selected events reported by Cursor and puts requests to read files, edits and chat-shortening events on one timeline.

Experimental release · Standalone companion tool

What to expect from this release

What you get
A hook recorder connected to a Cursor project, plus a separate Windows/browser timeline viewer. The viewer is a companion tool; it is not a new panel inside Cursor.
Verified so far
Recorder event handling, log checks, import failure cases and the timeline were tested using supplied events, real local processes and browser/package checks.
Still needs testing or implementation
Hook setup and a complete recording session in the actual Cursor app remain unverified. Reported read requests do not prove which files reached or influenced the model.
Relationship to the original app
Cursor's documented hooks provide the intended connection. Embedding the timeline in Cursor would require a separate extension or interface integration; the current package does not modify Cursor's executable.
